Integrations

Webhook Templates

Pre-built integrations for popular services. Point your webhook at Corral, then forward to any Stockyard tool.

Payment events

Stripe → Corral → Billfold
Capture Stripe payment webhooks and create invoices in Billfold automatically.
1. Set Stripe webhook URL to: http://your-server:8760/hooks/stripe
2. Corral captures and displays the full payload
3. Forward to Billfold: POST http://localhost:8710/api/invoices

Code events

GitHub → Corral → Bounty
Turn GitHub issues and PR comments into Bounty tickets.
1. Set GitHub webhook URL to: http://your-server:8760/hooks/github
2. Filter for issues.opened and issue_comment.created events
3. Forward to Bounty: POST http://localhost:9320/api/issues
GitHub Push → Pipeline
Trigger Pipeline jobs on every push to main.
1. Set GitHub webhook URL to: http://your-server:8760/hooks/github-push
2. Filter for push events on refs/heads/main
3. Forward to Pipeline: POST http://localhost:8800/api/jobs/trigger

Monitoring events

Bellwether → Sentinel → Slack
When Bellwether detects downtime, create a Sentinel alert and notify Slack.
1. Bellwether fires webhook on status change
2. Sentinel creates an incident: POST http://localhost:8730/api/alerts
3. Sentinel forwards to Slack incoming webhook
Uptime Alert → Paddock
Auto-update your status page when monitoring detects issues.
1. Bellwether fires webhook on downtime
2. Forward to Paddock: POST http://localhost:8680/api/incidents
3. Status page updates automatically

Communication events

Twilio → Corral
Capture incoming SMS and voice webhooks for debugging.
1. Set Twilio webhook URL to: http://your-server:8760/hooks/twilio
2. Corral captures SMS body, from number, and metadata
3. Replay to test your handler: click Replay in Corral dashboard
Slack → Corral → Dossier
Log Slack messages mentioning customers into your CRM.
1. Create Slack app with event subscription
2. Point events URL to: http://your-server:8760/hooks/slack
3. Forward customer mentions to Dossier: POST http://localhost:8700/api/contacts/note
