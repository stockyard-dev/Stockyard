Features

Unified Request Format

A single JSON schema for chat completions, embeddings, and image generation. Send the same request to any provider without translation layers.

Standardized Responses

Normalized response format with consistent token counts, finish reasons, and metadata. No more parsing provider-specific quirks.

Streaming Protocol

Server-sent events with standardized chunk format. Stream from any provider with identical client code and predictable delta shapes.

Error Taxonomy

Consistent error codes and retry semantics across all providers. Rate limits, context overflows, and content filters mapped to a shared vocabulary.
