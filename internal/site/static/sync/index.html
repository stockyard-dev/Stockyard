Connect tools together. Events in one tool trigger actions in another.

Built-in flows

Each tool exposes webhooks that other tools can consume. Configure a sync by pointing one tool's webhook URL at another tool's API.

How it works

Every Stockyard tool supports outgoing webhooks. When an event happens (new issue, downtime, error spike), the tool sends a POST request to a URL you configure. Point that URL at another Stockyard tool's API endpoint.

# Example: When Bellwether detects downtime, update Paddock status page
# In Bellwether config:
WEBHOOK_URL=http://localhost:8680/api/incidents

# Example: When Bounty gets a critical bug, alert via Sentinel
# In Bounty config:
WEBHOOK_URL=http://localhost:8730/api/alerts

Cross-tool queries

Since every tool uses SQLite, you can query across tools with standard SQL by attaching databases:

sqlite3 bounty.db "ATTACH 'headcount.db' AS analytics; SELECT issues.title, analytics.page_views.count FROM issues JOIN analytics.page_views ON issues.url = analytics.page_views.path;"
