Install Stockyard for Yoga & Pilates Studios

7 tools. 60 seconds. Your data stays on your machine.

Step 1 — Run one command

Open Terminal and paste this:

curl -fsSL https://stockyard.dev/for/yoga-studio/install.sh | bash

This downloads 7 tools into ~/stockyard-yoga-studio/ and creates start/stop scripts.

Don't have Terminal?

Mac: Press Cmd+Space, type "Terminal", press Enter.

Windows: Install WSL first, then open Ubuntu from the Start menu.

Linux: Press Ctrl+Alt+T.

Step 2 — Start your tools

Run the start script:

cd ~/stockyard-yoga-studio && ./start.sh

Your browser will open automatically. All tools run in the background.

License key

Activate unlimited access

After starting your 14-day trial, set your license key:

export STOCKYARD_LICENSE_KEY=SY-your_key_from_email

Add this line to ~/.bashrc or ~/.zshrc so it persists.

Your data lives in ~/stockyard-yoga-studio/data/. Back up by copying this folder. Move to a new computer by moving this folder. Standard SQLite files — open with any tool.
