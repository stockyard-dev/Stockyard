How it works

1

Calibrate

Drover replays real traces against candidate models and scores quality using the reference model (GPT-4o) as the benchmark.

2

Set a threshold

Pick a minimum quality score (default: 0.80). Any model that scores above this is eligible for routing.

3

Route automatically

Send model: "auto", model: "autopilot", or even model: "gpt-4o" — Drover transparently downgrades to the cheapest qualifying model. Every decision is logged with savings.

See it work

# Step 1: Calibrate models against real traffic $ curl -X POST https://stockyard.dev/api/autopilot/calibrate \ -H "X-Admin-Key: $KEY" → 3 models scored, 4 traces each, 7.2s total # Step 2: Send a request with model=auto $ curl https://stockyard.dev/v1/chat/completions \ -H "Authorization: Bearer $OPENAI_API_KEY" \ -d '{"model":"auto","messages":[{"role":"user","content":"hello"}]}' → Drover routed to gpt-4o-mini (quality: 0.885, cost: $0.000006) # Or: transparent downgrade from gpt-4o $ curl https://stockyard.dev/v1/chat/completions \ -d '{"model":"gpt-4o","messages":[{"role":"user","content":"hello"}]}' → Drover intercepted → gpt-4o-mini (25x cheaper, same quality tier)
