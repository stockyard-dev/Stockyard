What Fabric does

Declarative Manifests

Define your entire AI infrastructure as JSON. Models, middleware, routing, guardrails, billing, alerts, and more in one file.

Idempotent Deploys

Apply the same manifest twice and nothing changes. Fabric only modifies what has drifted from the desired state.

Drift Detection

Background loop checks platform state every 5 minutes. Detects when someone manually changes a setting and reverts it.

Auto-Healing

When drift is detected, Fabric automatically re-reconciles to the desired state. No manual intervention needed.

Version History

Every deployment is versioned. Roll back to any previous version with a single API call.

Diff Preview

Preview what changes a manifest would make before applying. Validate without deploying. Dry-run everything.

API

# Deploy a manifest curl -X POST /api/fabric/deploy \ -d '{"name":"my-app","model":"gpt-4o","modules":["cache","ratelimit"]}' # Preview changes without applying curl -X POST /api/fabric/diff \ -d '{"name":"my-app","model":"gpt-4o","modules":["cache"]}' # Roll back to version 2 curl -X POST /api/fabric/deployments/my-app/rollback?version=2 # Export current state as manifest curl -X POST /api/fabric/export/my-app
