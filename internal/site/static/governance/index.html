What Governance does

Proposals & Voting

Submit proposals and vote on platform changes with transparent tallying.

Dispute Resolution

Structured dispute process with arbiter assignment and evidence review.

Safety Certifications

Automated safety certification for published apps and knowledge bases.

Compliance Engine

Automated compliance checking with rule-based auto-fix capabilities.

The API

Submit proposals, cast votes, and certify app safety—all REST.

# Submit a governance proposal curl -X POST /api/governance/proposals \ -d '{"title":"Increase rate limits for verified users", "description":"Proposal to raise rate limits from 100 to 500 req/min", "category":"platform-policy"}' # Vote on a proposal curl -X POST /api/governance/proposals/{id}/vote \ -d '{"vote":"approve", "weight":1, "comment":"This benefits power users significantly"}' # Certify an app for safety curl -X POST /api/safety/certify/{app_id} \ -d '{"scope":"production", "checks":["content-safety","pii-detection","bias-audit"]}'
