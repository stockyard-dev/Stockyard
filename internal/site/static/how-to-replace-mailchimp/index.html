How to replace Mailchimp with self-hosted email.

Export your list, set up Pony Express, send emails from your own server. Takes about 20 minutes.

Why you would do this

Mailchimp's free tier dropped to 500 contacts in 2023. The Essentials plan starts at $13/mo for 500 contacts and scales to $350/mo at 50,000. If you send transactional emails (receipts, notifications, password resets), you are paying per email on a platform designed for marketing campaigns.

If Mailchimp is working for you and the price is fine, do not switch. This guide is for people where it is not.

What you need

A server or localhost to run Pony Express on, your Mailchimp subscriber export (CSV), and an SMTP provider (Amazon SES, Postmark, or your own mail server) for actual delivery.

Step by step

Step 1: Export your subscribers from Mailchimp

In Mailchimp, go to Audience, then All Contacts, then Export Audience. Download the CSV file. This contains email addresses, names, tags, and subscription dates. You will import this into Pony Express.

Step 2: Install Pony Express

Run the install script and start the server. Pony Express runs on port 8930 by default.

curl -fsSL https://stockyard.dev/ponyexpress/install.sh | sh
DATA_DIR=./data ponyexpress

Open http://localhost:8930/ui to see the dashboard.

Step 3: Import your subscribers

Use the API to import your CSV export. Pony Express accepts Mailchimp-format CSVs directly.

curl -X POST http://localhost:8930/api/subscribers/import \
  -F 'file=@mailchimp-export.csv'

This creates subscriber records with all tags and metadata preserved.

Step 4: Configure your SMTP provider

Set the SMTP environment variables before starting Pony Express. Amazon SES example:

SMTP_HOST=email-smtp.us-east-1.amazonaws.com \
SMTP_PORT=587 \
SMTP_USER=your-ses-smtp-user \
SMTP_PASS=your-ses-smtp-password \
SMTP_FROM=hello@yourdomain.com \
ponyexpress

Step 5: Send your first email

Create a template and send a test.

curl -X POST http://localhost:8930/api/emails \
  -H 'Content-Type: application/json' \
  -d '{"to": "test@example.com", "subject": "Test from Pony Express", "body": "It works."}'

Check the dashboard at /ui to see delivery status.

Honest limitations

What Pony Express does not do.

Pony Express does not have a visual email builder, landing pages, marketing automation sequences, or audience segmentation. It sends emails via API or templates. If your workflow depends on Mailchimp's drag-and-drop builder or automated drip campaigns, Pony Express is not the right replacement.

FAQ
Will my emails land in the inbox?
Deliverability depends on your SMTP provider's IP reputation and your DNS setup (SPF, DKIM, DMARC). Using a reputable provider like Amazon SES or Postmark helps significantly.
Can I send marketing campaigns?
Pony Express is designed for transactional emails. For marketing campaigns with templates and analytics, consider keeping Mailchimp for marketing and using Pony Express for transactional emails.
How much does Amazon SES cost?
Amazon SES charges $0.10 per 1,000 emails. For most teams, this is pennies per month compared to Mailchimp's per-contact pricing.
