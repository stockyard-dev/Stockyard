Deploy Stockyard

Three ways to get running. Pick whichever fits your infrastructure.

Option 1: One-line install (recommended)

Works on any Linux or macOS machine. Downloads a ~25MB static binary.

curl -fsSL https://stockyard.dev/install.sh | sh
export OPENAI_API_KEY=sk-...
stockyard

Dashboard at http://localhost:4200/ui

Option 2: Docker

docker run -d \
  -p 4200:4200 \
  -e OPENAI_API_KEY=sk-... \
  -v stockyard-data:/data \
  ghcr.io/stockyard-dev/stockyard:latest

Option 3: Railway (one-click cloud deploy)

Deploy to Railway with zero configuration. Set your API keys as environment variables.

Deploy on Railway

Railway provides managed hosting with auto-deploys from GitHub. Free trial available.

Multi-tool install

Install multiple standalone tools at once:

curl -fsSL stockyard.dev/install-tools.sh | sh -s -- bounty headcount strongbox

# Or use a bundle:
curl -fsSL stockyard.dev/install-tools.sh | sh -s -- --starter
curl -fsSL stockyard.dev/install-tools.sh | sh -s -- --devtools
curl -fsSL stockyard.dev/install-tools.sh | sh -s -- --ops
