Self-Hosted API Key Generator

Generate, store, validate, and revoke API keys from your own server. No Auth0, no third-party key management, no per-MAU pricing.

The problem with hosted key management

Auth0 charges based on monthly active users — free up to 7,500 MAU, then $23 per month for 1,000 MAU on the Essentials plan. AWS API Gateway charges $3.50 per million API calls plus $1 per million REST API keys. For teams that just need to generate API keys, validate them on incoming requests, and revoke them when needed, these services charge for authentication infrastructure you might not need. If your use case is "give each customer an API key and check it on every request," a dedicated key management tool is simpler and cheaper.

Deed — API key registry

Deed generates, stores, and manages API keys as a self-hosted service. Create a key with a name and optional scopes, get back an auto-generated key string. Validate keys against the registry. Revoke keys instantly. Set expiration dates. Track key metadata.

curl -fsSL https://stockyard.dev/deed/install.sh | sh
PORT=9700 ./deed

Generate a new API key:

curl -X POST http://localhost:9700/api/api_keys \
  -H 'Content-Type: application/json' \
  -d '{"name": "production-backend", "scopes": "read,write", "expires_at": "2027-01-01"}'

Validate a key from your application:

# In your request middleware:
# GET /api/api_keys?key=deed_xxxxxxxxxxxx
# Returns 200 with key metadata if valid, 404 if not

How teams use this

A SaaS company generates an API key for each customer through Deed's API during onboarding. The application middleware validates the key on every request by checking Deed. When a customer churns or reports a compromised key, the team revokes it through the dashboard. The entire key lifecycle — generation, validation, rotation, revocation — runs on one binary on the team's infrastructure. No third-party service sees the keys or the traffic patterns.

For more comprehensive auth

If you need OAuth flows, social login, MFA, or user management beyond API keys, Gate (auth proxy) handles session-based and API key authentication for upstream services. For a full identity platform, Auth0 or Keycloak offer more — but at significantly more operational or financial cost.
