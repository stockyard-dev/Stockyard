See it work

$ curl -fsSL stockyard.dev/install.sh | sh
✓ Stockyard installed (~25MB)

$ stockyard
29 products active · 76 modules · http://localhost:4200

# Send a request through the proxy
$ curl localhost:4200/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"hello"}]}'
{"choices":[{"message":{"content":"Hello! How can I help?"}}]}

# Replay that request against a different model
$ curl -X POST localhost:4200/api/replay \
  -d '{"trace_id":"tr_82a0da...","target_model":"claude-sonnet-4-20250514"}'
→ GPT-4o-mini: 454ms, $0.000006  |  Claude: 1,227ms, $0.000048

# Or let Autopilot pick the best model
$ curl localhost:4200/v1/chat/completions \
  -d '{"model":"autopilot","messages":[{"role":"user","content":"hello"}]}'
→ Routed to gpt-4o-mini (quality=0.88, 96% cheaper than gpt-4o)
