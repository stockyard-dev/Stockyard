Build Your Own

Create Custom Apps

Every Stockyard app is a Fabric manifest. Define your prompts, models, middleware, and routes — then publish to the App Store for others to discover and deploy.

# Install the Stockyard CLI curl -sSL https://stockyard.dev/install.sh | sh # Scaffold a new app stockyard app init my-custom-app # Test locally stockyard app dev # Publish to the App Store stockyard app publish
