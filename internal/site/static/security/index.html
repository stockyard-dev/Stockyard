Security

Enterprise-grade AI security by default.

Encryption at rest, hash-chained audit trails, prompt injection detection, PII redaction, and automated compliance. Built into the binary.

Data Protection

AES-256-GCM Encryption

Provider API keys are encrypted at rest using AES-256-GCM with a PBKDF2-derived encryption key (100K iterations). Keys are encrypted in internal/auth/crypto.go and never appear in logs, API responses, or trace data.

Secret Vault

All sensitive configuration (webhook URLs, Stripe keys, connection strings) stored in an encrypted vault. Referenced by name in Fabric manifests — never exposed in config files.

PII Redaction

Automatic detection and redaction of names, emails, phone numbers, SSNs, and credit card numbers before prompts reach the LLM provider. Configurable per module.

Audit & Compliance

Hash-Chained Audit Ledger

Every request gets a SHA-256 hash-chained entry in the Trust ledger. Each hash includes the previous entry, creating a tamper-evident chain that proves no records were modified or deleted.

Compliance Automation

Pre-built presets for HIPAA, GDPR, SOX, EU AI Act, and UK AI framework. One-click configuration applies the right modules and policies. Continuous monitoring alerts on non-compliance.

Trust Federation

Multiple Stockyard instances anchor audit chains to a shared verification network. Regulators verify compliance by checking published hash anchors — without accessing your data.

Threat Protection

Prompt Injection Detection

500+ attack patterns with ensemble detection: regex, heuristic, and keyword matching. Requests are scored 0-100 for injection risk. Configurable thresholds for block, warn, and allow.

Immune System

Shared threat intelligence across the platform. When any app detects an attack, the signature propagates to every other app within seconds. Every attack makes the platform stronger.

Honeypots

Deploy fake vulnerabilities that look exploitable. When an attacker tries to exploit them, their technique is captured, the threat library is updated, and all apps are immunized.

Incident Response

Recall

Recall finds every response affected by a model error in seconds. Search by text, regex, date range, and model. One-click notifications to affected parties.

Black Box Investigation

Reconstruct the complete context of any request: the full prompt, response, middleware execution chain, audit trail, billing record, and provider health at the time.

Safety Certification

Automated red-team testing grades every app A through F. Apps below D must improve before publishing. Scorecards run weekly for all published apps.

Architecture

Stockyard is a single statically linked Go binary with embedded SQLite. There are no external services, no network dependencies, and no shared infrastructure. Your data stays in your binary on your machine. The attack surface is minimal because there's nothing to attack except the binary itself.

Provider keys are encrypted before they touch disk. The encryption key derives from your admin key via HKDF. Even if someone accesses the SQLite database file, provider keys are unreadable without the admin key.

For enterprises requiring additional assurance: the entire codebase is open source at github.com/stockyard-dev/Stockyard. Audit it yourself.
