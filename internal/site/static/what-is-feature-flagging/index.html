What Is Feature Flagging?

A technique for toggling features on and off at runtime without deploying new code.

How it works

A feature flag is a conditional check in your application code: "is this feature enabled?" The answer comes from a flag service rather than being hardcoded. When the flag is off, the feature is hidden. When it is on, the feature is visible. Changing the flag does not require a deployment, a restart, or a code change — the application checks the flag on each request and adjusts its behavior accordingly.

# Without feature flags
def checkout():
    return new_checkout_flow()

# With feature flags
def checkout():
    if flags.get("new-checkout"):
        return new_checkout_flow()
    else:
        return old_checkout_flow()

Common use cases

Gradual rollouts — enable a feature for 5% of users, then 25%, then 100%. If something breaks at 5%, disable it instantly without rolling back a deployment.

Kill switches — disable a feature that is causing problems in production. The fix is instant — no waiting for CI/CD to build and deploy a rollback.

A/B testing — show different versions of a feature to different user groups and measure which performs better.

Trunk-based development — merge incomplete features to main behind a flag. The code is deployed but not visible until the flag is enabled. No long-lived feature branches.

The per-seat pricing problem

LaunchDarkly, the most popular feature flag service, charges per seat. At $10-20 per developer per month, the cost scales with your team size rather than your usage. For a feature that amounts to checking a boolean value on each request, the per-seat model prices the management layer rather than the compute.

Self-hosted feature flags

Salt Lick is a self-hosted feature flag service that runs as a single Go binary. Create flags through the dashboard or API. Check them from your application with a simple HTTP GET. No SDK required, no per-seat pricing, no sending your flag configuration to a third party. $0.99/month.

curl -fsSL https://stockyard.dev/saltlick/install.sh | sh
stockyard-saltlick
# Dashboard: http://localhost:8670/ui
