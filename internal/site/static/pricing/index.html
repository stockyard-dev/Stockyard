How it works
1

Download the binary

One command: brew install stockyard-dev/tap/stockyard or npx, docker, or curl.

2

Run it

Set your LLM API key, run the binary. Dashboard appears at localhost/ui.

3

Upgrade when you're ready

The free tier is production-ready. Cost routing is included at 100 requests/day, and the security quickscan gives you a free 5-probe audit. When you need unlimited routing, the full security suite, request replay, or other features — upgrade to unlock them. Set STOCKYARD_LICENSE_KEY=SY-... and restart.

Common questions
What do I get for free?
The full proxy with all 76 middleware modules, all 16 LLM providers, and unlimited requests. Self-hosted on your infrastructure. Cost routing is included at 100 requests/day. Security quickscan (5 probes) is free.
What's the difference between tiers?
Community is the full proxy, free forever. Individual ($29.99/mo) adds request replay, quality gates, and hallucination detection. Pro ($99.99/mo) adds unlimited cost routing, prompt evolution, load testing, chaos engineering, red-team testing, and all 29 platform products including RBAC and SSO.
Can I save with annual billing?
Yes. Annual plans save roughly 2 months: Individual $299.90/yr, Pro $999.90/yr.
What about the 150 standalone tools?
The LLM platform and the 150 standalone tools are separate products. The platform pricing on this page covers the proxy, routing, and LLM infrastructure. Stockyard Complete ($29/mo) bundles all 150 standalone tools. They can be used independently or together.
What providers are supported?
OpenAI, Anthropic, Gemini, Groq, Ollama, DeepSeek, xAI, Mistral, Cohere, Together, Fireworks, Perplexity, Replicate, Amazon Bedrock, Azure OpenAI, and Google Vertex AI. Any OpenAI-compatible endpoint works out of the box.
Do I need to change my application code?
No. Just point your OPENAI_BASE_URL at Stockyard. Works with the official OpenAI, Anthropic, and other provider SDKs — zero code changes required.
