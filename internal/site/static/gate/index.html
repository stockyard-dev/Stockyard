Quickstart

Up in 60 seconds.

Install
curl -fsSL https://stockyard.dev/gate/install.sh | sh
Run (point at your app)
GATE_UPSTREAM=http://localhost:3000 GATE_ADMIN_KEY=secret gate

  Stockyard Gate (Auth Proxy)
  Proxy:     http://localhost:8780 → http://localhost:3000
  Admin API: http://localhost:8780/gate/api
Issue an API key
curl -s -X POST http://localhost:8780/gate/api/keys \
  -H 'Authorization: Bearer secret' \
  -H 'Content-Type: application/json' \
  -d '{"name":"alice"}'

# Returns: {"key":"sk-gate-...","note":"Save this — not shown again"}

All requests to :8780 now require a valid API key or session cookie. Requests without auth return 401. The upstream at :3000 never needs to know auth exists.

Use cases

Three things teams use this for.

Lock down internal dashboards
Grafana, Metabase, or your custom admin panel — put Gate in front and no one gets in without an API key or a session login. No code changes to the underlying app.
Rate limit a shared API
Multiple services hitting one internal API. Gate enforces per-key rate limits and logs every request so you can see who's calling what and how often.
Add auth to a legacy service
Old service with no auth, can't be modified. Wrap it with Gate. Instant API key auth, access logs, and the ability to revoke keys without touching the service itself.
Why not heavier tools

OAuth is 2 days of work. Gate is 60 seconds.

Full OAuth2 flows, JWT middleware, or Authentik/Keycloak are the right answer when you have user-facing applications with complex permission trees. For internal tools, that's usually overkill. Gate handles the 90% case: your app needs auth, it doesn't have it, and you need to ship.

Single binary, embedded SQLite, no Redis, no Postgres. Set two environment variables and it runs. CORS headers and session login are built in for browser-based tools.

Scope

When Gate is all you need.

Gate is the right tool when the problem is specifically authentication and access control for internal services. It handles API keys, session auth, per-key rate limiting, and access logs. It doesn't do OAuth2, SAML, or fine-grained RBAC.

If you have a single internal tool that needs basic auth protection, or a small team that shares API keys for an internal service, Gate does the job cleanly without infrastructure overhead.

FAQ
Does Gate work with browser-based apps?
Yes. Set GATE_CORS_ORIGINS to enable CORS headers. Session login via POST /gate/login sets a cookie for browser clients.
Can I run multiple upstreams?
The free tier supports 1 upstream. Pro supports unlimited upstreams — run separate Gate instances, each pointing at a different service.
How does rate limiting work?
Set GATE_RPM for a global requests-per-minute limit. Limits are tracked per API key. Exceeding the limit returns 429 with a Retry-After header.
What's the license?
Apache 2.0. Free to use, modify, and deploy. No usage restrictions.
