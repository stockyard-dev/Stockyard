What Recall does

Full-text Response Search

Search across every LLM response your system has ever generated. Find the exact outputs that contained bad information, hallucinations, or policy violations.

Regex Pattern Matching

Use regular expressions to find complex patterns across responses. Match drug names, financial figures, legal citations, or any domain-specific content.

Date Range Filtering

Scope your search to the exact time window when the issue occurred. Narrow incidents from thousands of traces to just the affected ones.

Model-specific Filtering

Filter by model, provider, or any trace metadata. When a specific model hallucinates, find only the responses from that model and version.

One-click Notifications

Notify every affected customer via email, webhook, or custom channels. Batch notifications with context about what went wrong and corrected information.

Trace-level Acknowledgment

Track which affected traces have been acknowledged, corrected, or escalated. Full audit trail of your incident response for compliance and post-mortems.

The API

Create incidents, search affected traces, send notifications, and track resolution — all REST.

# Create an incident curl -X POST /api/recall/incidents \ -d '{"title":"Drug interaction hallucination", "severity":"critical", "description":"GPT-4o returned incorrect drug interaction info", "search":{"query":"ibuprofen safe with warfarin", "model":"gpt-4o", "from":"2026-03-20T00:00:00Z", "to":"2026-03-21T12:00:00Z"}}' # Search affected responses curl /api/recall/incidents/INC-042/traces?limit=50 # Search with regex pattern curl -X POST /api/recall/search \ -d '{"pattern":"(?i)safe.*(warfarin|coumadin)", "type":"regex", "model":"gpt-4o"}' # Send notifications to all affected users curl -X POST /api/recall/incidents/INC-042/notify \ -d '{"channel":"email", "message":"We identified an incorrect response..."}' # Acknowledge a specific trace curl -X POST /api/recall/traces/tr_8f2a1b/ack \ -d '{"status":"corrected", "note":"Customer contacted directly"}'
