Self-Hosted Tools

Each tool is a single Go binary with embedded SQLite. Install with the CLI, open the dashboard, done.

Install any tool
$ curl -fsSL stockyard.dev/cli/install.sh | sh
$ stockyard install bounty
$ stockyard start bounty
# Open http://localhost:9320/ui

LLM Proxy Platform

A single binary that sits between your app and LLM providers. 76 middleware modules, 38 providers, 360+ API endpoints.

Start the proxy
$ curl -fsSL stockyard.dev/install.sh | sh
$ OPENAI_API_KEY=sk-... stockyard
# Point your SDK at http://localhost:4200/v1
