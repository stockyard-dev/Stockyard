SDK Wrappers — 30 Seconds to Start

One import change. Zero config. All traffic routes through Stockyard automatically.

Installation

Python

pip install stockyard-openai

Node / TypeScript

npm install @stockyard/openai

Go

go get github.com/stockyard-dev/stockyard-openai-go

Usage — Before & After

Python

# Before from openai import OpenAI # After — one line change from stockyard_openai import OpenAI # Everything else stays the same client = OpenAI(api_key="sk-...") response = client.chat.completions.create( model="gpt-4o", messages=[{"role": "user", "content": "Hello"}] )

Node / TypeScript

// Before import OpenAI from 'openai'; // After — one line change import OpenAI from '@stockyard/openai'; // Everything else stays the same const client = new OpenAI({ apiKey: 'sk-...' }); const response = await client.chat.completions.create({ model: 'gpt-4o', messages: [{ role: 'user', content: 'Hello' }], });

Go

import stockyard "github.com/stockyard-dev/stockyard-openai-go" config := openai.DefaultConfig(os.Getenv("OPENAI_API_KEY")) config.BaseURL = stockyard.BaseURL() config.HTTPClient = &http.Client{Transport: stockyard.Transport()} client := openai.NewClientWithConfig(config)

How It Works

Each SDK wrapper subclasses (or wraps) the official OpenAI client and redirects the base_url to your Stockyard instance. Every request flows through Stockyard's middleware chain — caching, rate limiting, cost tracking, guardrails, audit logging — before reaching the LLM provider.

The wrappers add an X-Stockyard-Source header so you can filter traces by SDK in the Observe console.

FAQ

Does this add latency?
Minimal. Stockyard runs locally (or nearby) and adds <5ms to each request. Caching can actually reduce latency significantly for repeated queries.
What if Stockyard is down?
Set STOCKYARD_ENABLED=false to bypass. Or configure failover in Stockyard to automatically retry with a backup provider.
Can I use this with Azure OpenAI?
Yes. Configure your Azure endpoint as a provider in Stockyard, then the SDK wrapper routes through it seamlessly.
Can I add cost attribution tags?
Yes. Pass X-Stockyard-Tags as a default header: OpenAI(default_headers={"X-Stockyard-Tags": "team=backend,feature=search"})
