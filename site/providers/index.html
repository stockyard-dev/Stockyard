How it works

Set a provider's API key as an environment variable. Stockyard auto-detects it on startup and routes requests through the proxy. Every request gets the same middleware stack — caching, guardrails, rate limiting, tracing, and failover — regardless of provider.

# Set a provider key export OPENAI_API_KEY=sk-... export ANTHROPIC_API_KEY=sk-ant-... export DEEPSEEK_API_KEY=sk-... # Start Stockyard stockyard Providers: 3 detected (openai, anthropic, deepseek) Proxy ready at :7749 # Send requests to any detected provider curl http://localhost:7749/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{"model":"gpt-4o","messages":[{"role":"user","content":"hello"}]}'

For detailed setup instructions, env var names, and provider-specific notes, see the provider setup guide.

Don't see your provider?

Any OpenAI-compatible endpoint works with Stockyard. Set a custom base URL in your config and you are proxying in seconds. If your provider speaks the OpenAI protocol, it works.

# Any OpenAI-compatible endpoint export CUSTOM_PROVIDER_BASE_URL=https://your-endpoint.com/v1 export CUSTOM_PROVIDER_API_KEY=your-key
