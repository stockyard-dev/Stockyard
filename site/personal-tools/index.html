Self-Hosted Personal Tools

Every tool is a single binary with embedded SQLite. No Docker, no Postgres, no external dependencies.

Personal tools handle the most intimate data you generate: journal entries, health records, passwords, financial transactions, reading habits, and daily routines. When this data lives in Day One, MyFitnessPal, or Todoist, the service provider has a detailed behavioral profile of your daily life. Self-hosted personal tools ensure that your private data stays private — not private-according-to-a-terms-of-service, but private in the sense that the data physically exists only on hardware you control. No cloud sync, no analytics pipeline, no data broker has access because there is no third party in the architecture.

Where to start

Start with Notebook (notes), Cipher (passwords), and Almanac (journal). These three handle the most sensitive personal data — your thoughts, your credentials, and your daily reflections — and benefit the most from being self-hosted.
