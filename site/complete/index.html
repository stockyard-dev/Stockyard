After you subscribe

License key in your inbox within 5 minutes.

After checkout you'll receive a single license key — a string starting with SY-. Set it as the STOCKYARD_LICENSE_KEY environment variable on any tool binary to unlock Pro on that tool.

export STOCKYARD_LICENSE_KEY=SY-xxxxxxxxxxxxxxxxxxxx
./stockyard-mainspring

export STOCKYARD_LICENSE_KEY=SY-xxxxxxxxxxxxxxxxxxxx
./stockyard-cellar

The same key works across all tools, all instances, all servers.

FAQ
Do I need to run all 150 tools?
No. Download and run only what you need. Each is a standalone binary. The license key unlocks Pro on whatever you choose to run.
What's the difference between Complete and individual tool licenses?
Individual tool Pro licenses are $0.99–$4.99/mo per tool. Complete is $29/mo for all 150. If you use more than 6–7 tools, Complete is cheaper.
Does this include the main Stockyard LLM proxy platform?
The 150 standalone tools are separate from the Stockyard LLM proxy platform. Complete covers all 150 focused tools. The platform has its own pricing at /pricing/.
How many instances can I run?
Unlimited. Run each tool on as many servers as you need. The license is per organization, not per instance.
What happens if I cancel?
Your tools continue running on free tier limits. Pro features require an active license. Your data stays on your server — nothing is deleted or phone-home'd.
