See it work

# Install (~25MB binary, zero dependencies)
$ curl -fsSL stockyard.dev/install.sh | sh
✓ Stockyard installed

# Start — all 29 products, 76 modules, instant
$ stockyard
Chute:   http://localhost:4200/v1   ✓ 76 modules active
Console: http://localhost:4200/ui   ✓ 29 products

# Send a request (OpenAI-compatible, any provider)
$ curl localhost:4200/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"hello"}]}'
{"choices":[{"message":{"content":"Hello! How can I help?"}}]}

# Replay it against Claude to compare (Lasso):
$ curl -X POST localhost:4200/api/replay \
  -d '{"trace_id":"tr_82a...","target_model":"claude-sonnet-4-20250514"}'
→ Claude: 12.7% faster | same cost | quality: 0.88

# Let Drover pick the cheapest model automatically:
$ curl localhost:4200/v1/chat/completions \
  -d '{"model":"auto","messages":[{"role":"user","content":"hello"}]}'
→ Drover routed to gpt-4o-mini (96% cheaper than gpt-4o)
