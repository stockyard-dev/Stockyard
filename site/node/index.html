Why Run a Node

Earn by Running Inference

The Stockyard Mesh Network connects distributed compute providers with AI workloads. Run a node on your hardware and earn for every inference request you serve.

  • Passive income: Earn tokens for every request routed through your node
  • Flexible commitment: Run when you want, pause when you need to
  • Any hardware: GPUs, CPUs, or specialized accelerators
  • Automatic matching: Workloads are routed to the best-fit node

Setup

Node Setup Guide

01
Install the Stockyard CLI
One command to get started on Linux, macOS, or Windows.
02
Register Your Node
Create a node identity and link it to your Stockyard account.
03
Configure Models
Choose which models to serve based on your hardware capabilities.
04
Start Earning
Launch your node and begin serving inference requests.
# Install curl -sSL https://stockyard.dev/install.sh | sh # Register node stockyard node register --name my-gpu-node # Configure and start stockyard node start --model llama-3-70b --gpus 2
