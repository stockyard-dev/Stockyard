Reference

Manifest Reference

A Fabric manifest is a JSON document that describes the desired state of your deployment. Every manifest requires three top-level fields.

FieldTypeDescription
apiVersionstringManifest version, currently fabric/v1
kindstringResource type: Deployment, Route, or Middleware
metadataobjectName, namespace, labels, and annotations
specobjectResource-specific configuration

spec.scaling

FieldTypeDefaultDescription
minReplicasint1Minimum number of replicas
maxReplicasint10Maximum number of replicas
targetUtilizationfloat0.75CPU/GPU utilization target for autoscaling
cooldownSecondsint300Seconds to wait before scaling down

API

API Reference

All Fabric API endpoints require authentication via the Authorization: Bearer <token> header.

POST /api/v1/fabric/apply Apply a manifest
GET /api/v1/fabric/status Current deployment status
GET /api/v1/fabric/status/:name Status of a specific deployment
GET /api/v1/fabric/history Deployment version history
POST /api/v1/fabric/rollback Rollback to a previous version
GET /api/v1/fabric/diff Compare two manifest versions
DELETE /api/v1/fabric/deployments/:name Delete a deployment

Examples

Examples

Basic Deployment

// Deploy a single-model gateway { "apiVersion": "fabric/v1", "kind": "Deployment", "metadata": { "name": "my-gateway" }, "spec": { "provider": "openai", "model": "gpt-4o", "replicas": 1 } }

Multi-Model with Middleware

// Production setup with rate limiting and audit { "apiVersion": "fabric/v1", "kind": "Deployment", "metadata": { "name": "production", "namespace": "prod" }, "spec": { "routes": [ { "path": "/chat", "provider": "openai", "model": "gpt-4o" }, { "path": "/embed", "provider": "openai", "model": "text-embedding-3-large" }, { "path": "/fast", "provider": "anthropic", "model": "claude-3-haiku" } ], "middleware": ["rate-limiter", "cost-tracker", "audit-logger"], "scaling": { "minReplicas": 2, "maxReplicas": 20, "targetUtilization": 0.7 } } }

Apply via CLI

# Apply a manifest file stockyard fabric apply -f manifest.json # Check status stockyard fabric status production # View history stockyard fabric history production # Rollback to version 3 stockyard fabric rollback production --to-version 3
