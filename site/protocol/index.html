The Stockyard Protocol

Three open specifications that define how AI systems communicate, transact, and govern themselves. Permissively licensed. Designed for adoption.

Spec 01
AI Inference Protocol
How requests flow between nodes, providers, and apps. Message format, routing, authentication, error handling.
Spec 02
AI Governance Protocol
How compliance, audit, and safety are verified. Trust chain format, verification protocol, certification schema.
Spec 03
AI Commerce Protocol
How transactions, reputation, and knowledge are exchanged. Billing format, reputation schema, knowledge interchange.

Why an Open Protocol

Every AI system is an island. Agents can't talk to agents. Audit trails don't interoperate. Billing systems don't connect. The Stockyard Protocol changes this by defining a common language for AI infrastructure.

The protocol is designed for adoption: minimal required fields, extensible via metadata, and permissively licensed. Any platform can implement it. Stockyard is the reference implementation.

Trace Format (Core)

FieldTypeDescription
idstringUnique trace identifier
servicestringService name (default: "proxy")
operationstringOperation type (chat_completion, embedding)
statusstring"ok" or "error"
created_atstringRFC 3339 timestamp
providerstringLLM provider (openai, anthropic, etc.)
modelstringModel identifier
duration_msintegerRequest duration
tokens_inintegerInput token count
tokens_outintegerOutput token count
cost_usdnumberEstimated cost
metadata_jsonobjectExtension metadata
