Stockyard Fence

API Key Vault for Teams

Store, rotate, and audit API keys. One binary. Every access logged.

The problem

API keys live in .env files, Slack DMs, and 1Password vaults. When someone leaves, nobody knows which keys they had. When a key leaks, nobody knows who used it last.

How Fence works

Fence stores encrypted API keys in SQLite. Teams access keys through a REST API or CLI. Every access is logged with who, when, and from where. Keys rotate on schedule.

# Store a key
fence store openai-prod sk-proj-abc123 --team backend

# Retrieve (logged)
fence get openai-prod

# Audit trail
fence audit openai-prod

Features

AES-256-GCM encryption at rest. Per-team access scoping. Automatic rotation schedules. Audit log with IP and identity. CLI and REST API. Webhook alerts on access anomalies.
