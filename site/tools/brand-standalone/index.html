Stockyard Brand

Audit Trail for Any App

SHA-256 hash-chained ledger. Tamper-evident. POST events, export evidence packs.

The problem

Your SOC2 auditor asks for evidence that data access is logged and the logs have not been modified. You need an audit trail that proves integrity, not just a log table.

How Brand works

Brand is a standalone audit ledger. POST events from your app. Each event is SHA-256 hashed with the previous event hash, creating a tamper-evident chain.

# Record an event
curl -X POST localhost:8803/api/events \
  -d '{"actor":"alice@corp","action":"viewed","resource":"patient-1234"}'

# Verify chain integrity
curl localhost:8803/api/verify

# Export evidence pack
curl localhost:8803/api/evidence/export?from=2026-01-01

Features

SHA-256 hash chain. Chain verification API. Evidence pack export. SOC2/HIPAA/GDPR policy templates. REST API. Webhook on chain break.
