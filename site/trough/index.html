Quickstart

Up in 60 seconds.

Install, run, register an upstream, and every proxied request is tracked.

Install
curl -fsSL https://stockyard.dev/trough/install.sh | sh
Run
TROUGH_ADMIN_KEY=secret trough

  Stockyard Trough dev
  Proxy:   http://localhost:8790/proxy/{upstream_id}/...
  Spend:   http://localhost:8790/api/spend
Register an upstream and add a cost rule
curl -s -X POST http://localhost:8790/api/upstreams \
  -H 'Authorization: Bearer secret' \
  -d '{"name":"twilio","base_url":"https://api.twilio.com"}'
# Returns upstream ID

curl -s -X POST http://localhost:8790/api/upstreams/{id}/rules \
  -H 'Authorization: Bearer secret' \
  -d '{"path_pattern":"/2010-04-01/Accounts/*/Messages","cost_cents":79}'

# Now proxy through Trough instead of calling Twilio directly:
# http://localhost:8790/proxy/{id}/2010-04-01/Accounts/.../Messages
Use cases

Three things developers use this for.

Track Twilio/SendGrid spend
You're sending SMS or email in bulk and have no idea what it costs until the bill arrives. Point Trough at the API, set your per-request price, and get daily cost breakdowns.
Monitor internal service usage
Multiple apps call one internal API. Trough tells you which app calls which endpoints most, what the latency looks like, and flags unusual spikes.
Set spend alerts before the billing cycle
Trough fires a webhook when daily or monthly spend crosses a threshold. Catch runaway usage before it shows up on an invoice.
Why not heavier tools

Datadog and CloudWatch are expensive overkill for a single API.

Full observability platforms solve the right problem at the wrong scale for small teams. You just want to know: what does this API cost us, which endpoints are hot, and when should I be worried? Trough answers those three questions with a binary you run on your own infrastructure.

No agents. No cloud accounts. No per-seat pricing. Single binary, embedded SQLite, cost rules you define, webhook alerts when spend gets high.

Scope

When Trough is all you need.

Trough is the right tool when you want cost tracking for HTTP APIs without standing up a full observability stack. It handles per-endpoint cost rules, daily breakdowns, and spend alerts. It doesn't replace distributed tracing or APM.

The free tier covers 10,000 requests per month. Pro removes that limit and adds unlimited upstreams for $2.99/month.

FAQ
Does Trough modify my requests?
No. It proxies requests as-is and records metadata. The upstream never knows Trough is in the path.
How do cost rules work?
You define rules per upstream: method, path pattern (supports wildcards), and cost in cents. Trough matches each request to the first matching rule and records the cost.
Can I run multiple upstreams?
Yes. Each upstream gets its own proxy path and its own set of rules. Pro removes limits on the number of upstreams.
