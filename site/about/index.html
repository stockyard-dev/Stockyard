We build the tools you should own.

Stockyard is a family of 150 self-hosted developer tools. Single binary. SQLite. Your data, your server, your rules.

In early 2026, I was building an app with the OpenAI API. Within the first week, three things went wrong: an uncapped test run cost me $47, a provider outage took down my demo, and I had no way to prove to a client that their data hadn’t been logged. I needed a proxy, a cost tracker, an audit trail, and a cache. Four tools, four configs, four points of failure.

So I wrote a Go binary that did all four. Then I kept going.

Every line is Go. The database is embedded SQLite in WAL mode. The dashboard is a Preact SPA served from the same binary. Provider keys are encrypted at rest with AES-256-GCM. The middleware chain processes 76 modules in 400 nanoseconds. There are no external dependencies — no Redis, no Postgres, no Docker, no Node.js runtime.

You install it with one curl, run it with one command, and point your app at it. That’s the entire deployment.

Why one binary

I chose Go because it compiles to a static binary. I chose SQLite because it embeds. I chose to put everything in one process because the alternative is worse.

The LLM middleware ecosystem has dozens of standalone tools. A proxy here, an observability layer there, a cost tracker somewhere else, a safety filter from another vendor. Each one needs its own deployment, its own database, its own monitoring. The complexity compounds faster than the value.

Stockyard’s bet is that a single, well-integrated binary beats a constellation of microservices. The proxy, the tracer, the cost tracker, the audit ledger, the cache, the workflow engine, the prompt manager — they all share one database, one process, one config. When the rate limiter blocks a request, the tracer records it, the cost tracker skips it, and the audit ledger hashes it. In one function call chain, not across three network hops.

What’s here today

The core is real and works: Chute with 76 middleware modules and 40 provider integrations. Lookout for tracing, cost tracking, and anomaly detection. Brand for a hash-chained, tamper-evident audit ledger. Tack Room for prompt versioning and A/B testing. Forge for DAG workflows. Trading Post for config pack sharing.

Beyond the core, the platform includes billing with Stripe integration, team management with RBAC, conversational memory, an AI incident response system, a natural language control interface, a no-code app builder, a knowledge marketplace, a reputation system, and a governance framework. All built, all deployed, all accessible via API.

I won’t pretend every one of these 150 tools is battle-tested at scale. The proxy is. The observer is. The trust ledger is. The rest are functional and complete but new. This is an honest assessment. You can read the code and judge for yourself.
