How to Self-Host a CRM

Step-by-step guide to running Dossier as a self-hosted CRM on your own server. Install, configure, import contacts, and set up backups in under 15 minutes.

This guide walks you through setting up Dossier — a self-hosted CRM that runs as a single binary with embedded SQLite. By the end, you will have a working CRM with contacts, deal tracking, and search running on your server with automatic backups.

Prerequisites

A Linux server (Ubuntu 22.04+, Debian 12+, or any modern distro) with shell access. Dossier uses about 20MB of disk and negligible RAM. Any VPS, home server, or Raspberry Pi will work.

Step 1: Install

Download and install the binary with the one-line installer:

curl -fsSL https://stockyard.dev/dossier/install.sh | sh

This downloads the static binary to your current directory. No package manager, no Docker, no dependencies.

Step 2: Run as a systemd service

For production use, run Dossier as a systemd service so it starts on boot and restarts on failure:

sudo mv dossier /usr/local/bin/
sudo mkdir -p /var/lib/dossier

cat <<EOF | sudo tee /etc/systemd/system/dossier.service
[Unit]
Description=Dossier CRM
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/dossier
Environment=PORT=9700
Environment=DATA_DIR=/var/lib/dossier
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now dossier

Check that it is running: curl -s localhost:9700/api/health should return {"status":"ok"}.

Step 3: Import your contacts

If you are migrating from HubSpot, Pipedrive, or a spreadsheet, export your contacts as CSV, then use a script to import them via the API:

#!/bin/bash
# import_contacts.sh — reads CSV and POSTs to Dossier
while IFS=, read -r name email company phone; do
  curl -s -X POST http://localhost:9700/api/contacts \
    -H 'Content-Type: application/json' \
    -d "{"name":"$name","email":"$email","company":"$company","phone":"$phone"}"
done < contacts.csv

Step 4: Set up backups

Dossier stores everything in a single SQLite file at /var/lib/dossier/dossier.db. Back it up with a cron job:

# Daily backup at 2 AM
echo '0 2 * * * cp /var/lib/dossier/dossier.db /var/backups/dossier-$(date +\%Y\%m\%d).db' | sudo crontab -

To restore from a backup, stop the service, replace the database file, and restart.

Step 5: Put it behind a reverse proxy

For HTTPS access, put Dossier behind nginx with a Let's Encrypt certificate:

server {
    listen 443 ssl;
    server_name crm.yourdomain.com;

    ssl_certificate /etc/letsencrypt/live/crm.yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/crm.yourdomain.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:9700;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

Step 6: Use it

Open https://crm.yourdomain.com/ui in your browser. The dashboard lets you create contacts, search by name or company, filter by status, and manage deals. Double-click any contact to edit it. The stats panel shows total contacts and breakdown by status.

Every operation is also available through the REST API at /api/contacts, so you can integrate Dossier with your email client, marketing tools, or automation scripts.
