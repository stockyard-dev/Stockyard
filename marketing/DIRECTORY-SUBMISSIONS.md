**Long (under 500 chars):**
Stockyard is a self-hosted LLM proxy and control plane that ships as a single Go binary with zero external dependencies. It includes 66 runtime-toggleable middleware modules (cost caps, caching, rate limiting, PII redaction, prompt injection detection, failover), 16 LLM provider integrations, and 16 integrated apps covering observability, compliance audit trails, prompt management, workflow orchestration, and more. Embedded SQLite, MIT licensed, free forever for self-hosted deployments.
